監視リポジトリ

チェックを外したリポジトリは取得しません（候補として config.json に残ります）。 チェックの変更はその場で保存され、下の入力欄の内容も一緒に保存されます。

追加・削除は1行に1つ。owner/name か GitHub の URL。保存すると config.json が書き換わり、すぐ再取得します。

取得の設定

GitHub API の消費に直結する項目。変更するとその場で config.json に保存され、次の取得から反映されます （config.json を手で編集する必要はありません）。
